RNA-seq experiment parameters

Fill in every field, then download the file and drop it into your experiment's FASTQ folder — the same folder that holds the cntl and test subdirectories.

The downloaded file must keep the name input_args.json. The pipeline looks for that exact name and will not find it under any other.

Run
Experiment

A shared name for a set of experiments run as one design with exactly one thing varied — a timecourse, a dose series, a co-treatment pair. Every member gets the identical label.

Experiment folders are named <cell_line>_<perturbation_agent>_<what varies>_<date>. The series label is that same name with the varying value removed, so it comes out identical for every member and nothing has to be invented:

Timepoint series — folders Akata_anti-IgG_24hr_2022-12-08 and Akata_anti-IgG_48hr_2022-12-08
→ label Akata_anti-IgG_2022-12-08
Co-treatment pair — folders Mutu_Zta_EXOSC3-KO_2025-08-31 and Mutu_Zta_EXOSC3-control_2025-08-31
→ label Mutu_Zta_EXOSC3_2025-08-31 (the target stays, only the arm drops)

Leave blank if this experiment is not part of a series.

What differs between the members of that series — exactly one thing, so this and Co-treatment type are mutually exclusive:

• Set a co-treatment type → this locks to co_treatment, since the thing that differs between the two halves of a pair is always the treatment.
• Pick any other axis here → Co-treatment type collapses to none and locks, and its target/arm fields disappear.
• Clear this field to get the co-treatment choice back.

co_treatment is never selectable by hand: it is only ever correct alongside a real co-treatment type, and in that case it is already filled in for you.
